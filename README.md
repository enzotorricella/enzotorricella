## Proyectos de producto

> Estos son productos de mi trayectoria. Sus repositorios completos no necesariamente son públicos; los enlaces se ofrecen como referencias de producto, no como acceso al código fuente.

### Kardexa — Punto de venta y gestión comercial

Sistema para ventas, inventario y operación diaria en pequeños comercios, con enfoque en funcionamiento offline.

- **Tecnologías:** C#, .NET MAUI, SQLite, Windows.
- **Problemas abordados:** ventas, stock, reglas de negocio e integración con periféricos.

### EventChecking / EventStaff — Gestión de asistentes

Solución para registro, acreditación y control de acceso mediante códigos QR.

- **Tecnologías utilizadas:** ASP.NET Core, React, SQL Server.
- **Problemas abordados:** gestión de registros, flujos de acreditación y control de acceso.
- [Sitio del producto](https://www.eventchecking.com.ar/)

### Talvo Dry — Operaciones móviles

Aplicación orientada a registros diarios, novedades y seguimiento de conductores.

- **Tecnologías:** .NET MAUI.
- **Problemas abordados:** captura de datos y flujos operativos desde dispositivos móviles.
